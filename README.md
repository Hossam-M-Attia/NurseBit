# NurseBit · Your PC's personal nurse

**عربي:** برنامج صيانة وتسريع للويندوز للمستخدم العادي والجيمرز، من LinGO EG.
بيفحص جهازك، بينضّفه، بيصلّحه، وإنت اللي بتقرر. مش بيبعت أي بيانات عنك.

**English:** A Windows maintenance and speed-up app for everyday users and gamers, by LinGO EG.
It checks, cleans and fixes your PC, and you decide. It sends no data about you.

## التحميل · Download
من **Releases** على اليمين، نزّل `NurseBit-Setup-<النسخة>.exe` وشغّله.
لو البرنامج متسطّب عندك، الملف نفسه بيحدّثه. وبعد كده التحديثات بتوصلك من جوه البرنامج: الإعدادات ← دوّر على تحديث.

Download `NurseBit-Setup-<version>.exe` from **Releases** on the right and run it.
If NurseBit is already installed, the same file updates it. After that, updates come from inside the app: Settings › Check for updates.

## اتأكد إن الملف أصلي · Verify the file
بصمة كل ملف موجودة في `SHA256.txt` جنبه. في PowerShell:
```
Get-FileHash .\NurseBit-Setup-1.2.0.exe
```
لازم الرقم يطابق اللي في `SHA256.txt`.
